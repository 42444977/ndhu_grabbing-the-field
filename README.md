## 功能介紹

| 功能 | 說明 |
|------|------|
| 🖥️ 現代化 GUI | `tkinter` 明亮主題卡片風，紫色主色 `#6d28d9`，標楷體 |
| ⏰ 定時啟動 | 可設定未來時間（時/分/秒），到時間才開啟瀏覽器執行整個流程 |
| 🛰️ 伺服器校時 | 登入後讀取網頁 `currTime`，計算本機與系統時間差，搶場倒數用校正後時間 |
| 🎯 精準搶場 | 校時後高精度倒數，到達搶場時間立刻觸發查詢／申請 |
| 🤖 OCR 驗證碼 | 使用 `ddddocr` 自動截圖辨識，最多重試 10 次 |
| 🔥 不演了 | 開啟後跳過驗證碼後的安全等待，搶到場直接送出 |
| 💾 設定記憶 | 自動記住帳號、密碼（XOR + base64 混淆）、運動類型、場地、場次、時間、停留模式 |
| 🪟 完成後停留 | 可選 10／20／30／60／120 秒或「不自動關閉」 |
| 🧵 背景執行緒 | Selenium 跑在 daemon thread，GUI 即時顯示狀態與日誌不卡頓 |
| 🚫 防誤觸下拉 | 滑鼠滾輪不會改變選中值，選完自動清除反白 |
| 🏸 多場地支援 | 排球、籃球、體育館、操場、網球場、戶外大型球場 |
| 🧪 練習模式 | 預約兩週前兩天且不送出，可走完完整流程測試 |
| 🔒 密碼遮罩切換 | 👁 按鈕一鍵切換密碼明文 / 遮罩 |

## 系統需求

- **作業系統**：Windows 10 / 11（macOS 未測試）
- **Python 版本**：`3.8` ~ `3.12`（ddddocr 對 3.13+ 有相容性問題）
- **瀏覽器**：Google Chrome（Selenium 4.6+ 會自動配對 ChromeDriver）

## 安裝步驟

### 1. 安裝 Python 套件

```bash
pip install selenium ddddocr
```

> `tkinter` 為 Python 標準函式庫，通常已內建，無需另外安裝。

#### 套件說明

| 套件 | 版本建議 | 用途 |
|------|----------|------|
| `selenium` | `≥ 4.6` | 控制 Chrome 進行自動化操作，4.6+ 內建 driver 管理 |
| `ddddocr` | 最新版 | OCR 模型，辨識網頁驗證碼圖片 |
| `tkinter` | 內建 | GUI 視窗介面 |
| `threading` / `queue` | 內建 | 將 Selenium 放在背景執行緒，GUI 不卡頓 |
| `tempfile` | 內建 | 驗證碼暫存圖寫到系統 temp 目錄 |
| `base64` | 內建 | 密碼混淆儲存 |

---

### 2. 安裝 ChromeDriver

Selenium 4.6+ 已內建 driver 自動下載，多數情況下無需手動安裝。若遇到 `SessionNotCreatedException`：

**Step 1**：確認 Chrome 版本（瀏覽器右上角 → 說明 → 關於 Google Chrome）
**Step 2**：至 [Chrome for Testing](https://googlechromelabs.github.io/chrome-for-testing/) 下載對應版本
**Step 3**：將 `chromedriver.exe` 放至 `搶場機器人7.0.py` 同資料夾，或加入系統 `PATH`

---

### 3. 執行程式

```bash
python 搶場機器人7.0.py
```

## 使用說明

啟動後會出現 GUI 視窗，分為四個卡片區塊：

### 📇 帳號 / 密碼

| 欄位 | 說明 | 範例 |
|------|------|------|
| **學號** | 東華學號（自動補上 `@gms.ndhu.edu.tw`） | `411225047` |
| **密碼** | 學校信箱密碼，可按 👁 切換顯示 | `********` |
| **記住密碼** | 勾選後密碼以 XOR + base64 混淆儲存至 `%APPDATA%` | ✔ |

### 🏟️ 運動類型 / 場地 / 場次

| 欄位 | 說明 | 範例 |
|------|------|------|
| **運動類型** | 下拉選擇大類別 | 排球 |
| **場地** | 依運動類型自動更新對應場地清單 | `VOL0F排球場F-男` |
| **場次** | 選擇欲預約的時段 | `17:00-19:00` |

### ⏰ 定時啟動 / 搶場時間

| 欄位 | 說明 |
|------|------|
| **啟用定時啟動** | 勾選後到設定時間才開啟瀏覽器；不勾選就立刻開始 |
| **啟動時間** | 開瀏覽器登入的時間（HH:MM:SS） |
| **搶場時間** | 在網頁上按「查詢」的時間（HH:MM:SS），會用校正後時間倒數 |

### ⚙️ 其他設定

| 欄位 | 說明 |
|------|------|
| **借用原因** | 送出申請時填入的理由（例：`我要練球`） |
| **完成後頁面停留時間** | 10／20／30／60／120 秒或「不自動關閉」 |
| **正式搶場 / 練習模式** | 勾選 = 正式送出；未勾選 = 練習模式 |
| **🔥 不演了** | 開啟後跳過驗證碼後的安全等待秒數，搶到場立刻送出（預設關閉） |

填寫完畢後按下「**開始搶場**」，畫面會切換到執行頁面，顯示即時狀態列、執行日誌與取消按鈕。

### 搶場日期邏輯

```
今日 → 下一週 → 下一週 → 前一天
= 兩週後的前一天
```

- **正式模式**：登入後先校時，等到設定的搶場時間後才觸發查詢
- **練習模式**：日期再往前一天（共兩週前兩天），且**不等待時間**，直接執行完整流程但**不送出**最終申請

### 「不演了」按鈕

預設關閉。系統會根據驗證碼是第幾次猜中決定一個額外等待秒數（一次中 → 2 秒、二次 → 1 秒、三次 → 0.5 秒），用來緩衝伺服器處理速度，提升送出成功率。

開啟「不演了」後直接跳過這段等待，搶到場立刻按下送出。**爭時間優先、容錯次之**，建議只在熟悉流程後再開。

## 運作流程

```
啟動 GUI（讀取上次設定）
    │
    ├─ 填寫四張卡片 → 按下「開始搶場」
    │
    ▼
切換到執行頁面（即時狀態 + 執行日誌）
    │
    ├─ [若啟用] 等待定時啟動時間
    │
    ├─ 開啟 Chrome，前往東華體育場地借用系統
    │
    ├─ 輸入帳號密碼 → 登入
    │
    ├─ [正式模式] 讀取網頁 currTime 校時
    │
    ├─ 點擊「新增申請」
    │
    ├─ 選擇運動類型、場地
    │
    ├─ 日期導航：今日 → +1週 → +1週 → -1天
    │       (練習模式再 -1 天)
    │
    ├─ [正式模式] 使用校正後時間倒數至搶場時間
    │
    ├─ 點擊「查詢」→ 點擊目標場次「申請」
    │
    ├─ OCR 辨識驗證碼（最多 10 次重試）
    │       ├─ 截圖到系統 temp 目錄
    │       ├─ ddddocr 辨識
    │       ├─ 填入驗證碼 → 點擊確認
    │       └─ 確認按鈕消失 → 驗證成功
    │
    ├─ 自動填入借用原因
    │
    ├─ [正式模式]
    │     ├─ 「不演了」關閉 → 等待 0~2 秒 → 送出申請
    │     └─ 「不演了」開啟 → 直接送出申請
    │
    └─ [練習模式] 顯示完成訊息（不送出）
    │
    ▼
依「完成後頁面停留時間」決定瀏覽器關閉時機
```

## 設定檔位置

所有設定會自動儲存到：

```
%APPDATA%\NDHU_Booking\config.json
```

包含欄位：學號、密碼（XOR + base64 混淆字串）、是否記住密碼、運動類型、場地、場次、借用原因、模式、定時啟動相關時間、搶場時間、停留模式、不演了狀態。

> 想恢復全部預設值，刪除這個檔案即可。
> 不勾選「記住密碼」時，存到檔案的密碼欄位會清空。

## 常見錯誤與排查

### ❌ `SessionNotCreatedException` / ChromeDriver 版本不符

**原因**：ChromeDriver 版本與 Chrome 瀏覽器不符。

**解決**：
1. 確認 Chrome 版本（瀏覽器右上角 → 關於 Google Chrome）
2. 至 [Chrome for Testing](https://googlechromelabs.github.io/chrome-for-testing/) 下載對應版本
3. 或升級 Selenium 至 4.6+（支援自動管理 driver）

---

### ❌ `ModuleNotFoundError: No module named 'ddddocr'`

**原因**：未安裝 ddddocr。

**解決**：
```bash
pip install ddddocr
```

> 若安裝時出現 `onnxruntime` 相關錯誤，可嘗試：
> ```bash
> pip install onnxruntime --force-reinstall
> pip install ddddocr
> ```

---

### ❌ `ModuleNotFoundError: No module named 'selenium'`

**解決**：
```bash
pip install selenium
```

---

### ❌ 登入失敗 / 找不到登入按鈕

**可能原因**：
- 帳號密碼錯誤
- 系統網站暫時維護

**解決**：
1. 確認帳號（學號）與密碼正確
2. 手動嘗試登入 [東華體育場地借用系統](https://sys.ndhu.edu.tw/gc/sportcenter/SportsFields/Login.aspx)

---

### ❌ 驗證碼辨識失敗（超過 10 次）

**可能原因**：
- 驗證碼圖片解析度不足或模糊
- ddddocr 對特定字型辨識率較低

**解決**：
1. 確認 `ddddocr` 為最新版本：`pip install ddddocr --upgrade`
2. 若持續失敗，可手動調整程式碼中的 `max_retries` 參數（預設 10）

---

### ❌ 運動類型或場地選擇失敗

**可能原因**：
- 學校系統更新了場地名稱
- 選擇的場地文字與系統下拉選單不符

**解決**：
- 手動開啟借用系統，確認場地清單名稱，並更新程式碼 `VENUES_DICT` 中的對應字串

---

### ❌ `TimeoutException`：等待元素逾時

**可能原因**：網路速度過慢，頁面載入超過預設等待時間（10~15 秒）。

**解決**：
- 確保網路連線穩定
- 可適當調大 `WebDriverWait(driver, 10)` 中的秒數

---

### ⚠️ 校時失敗（`無法讀取網頁 currTime 內容`）

**原因**：登入後頁面尚未把 `currTime` 寫入 DOM。

**解決**：程式會自動退回使用本機時間繼續執行，仍可正常搶場，只是精度略降。日誌會顯示「校時失敗，將使用本機時間」。

---

### ❌ 設定無法儲存

**原因**：`%APPDATA%\NDHU_Booking\` 無寫入權限或路徑不存在。

**解決**：手動到 `%APPDATA%` 建立 `NDHU_Booking` 資料夾，或以系統管理員身份執行程式一次。

---

## 注意事項

> 1. 本程式僅供**個人學習與研究**用途，請勿用於惡意搶占場地。
> 2. 密碼以 XOR + base64 混淆儲存，**僅防偷看，並非加密**，請勿在共用電腦勾選「記住密碼」。
> 3. 驗證碼暫存圖寫到系統 temp 目錄，辨識後自動刪除。
> 4. 完成後可選擇瀏覽器停留時間，預設「不自動關閉」方便確認結果。
> 5. 若學校系統更新 UI 或 HTML 結構，部分 XPath / Element ID 可能需要重新確認。
> 6. 「不演了」開啟後會跳過容錯緩衝，若搶場當下伺服器特別忙，建議保持關閉。
