# 🏟️ 搶場機器人

> 東華大學體育場地自動預約機器人，支援 GUI 操作、OCR 驗證碼辨識與精準計時搶場。

## 功能介紹

| 功能 | 說明 |
|------|------|
| 🖥️ GUI 介面 | 使用 `tkinter` 建立視覺化操作視窗，無須修改程式碼 |
| ⏰ 精準計時搶場 | 監聽網頁伺服器時間，於指定秒數自動觸發查詢與申請 |
| 🤖 自動辨識驗證碼 | 使用 `ddddocr` OCR 模型，自動截圖並辨識，最多重試 10 次 |
| 🏸 多場地支援 | 涵蓋排球、籃球、體育館、操場、網球場、戶外大型球場 |
| 🧪 練習模式 | 不送出申請，僅走完完整流程以供測試 |
| 🔒 密碼顯示切換 | 眼睛按鈕切換密碼明文 / 遮罩顯示 |

## 系統需求

- **作業系統**：Windows 10 / 11（macOS 未測試）
- **Python 版本**：`3.8` 以上
- **瀏覽器**：Google Chrome（版本需與 ChromeDriver 相符）

---

## 安裝步驟

### 1. 安裝 Python 套件

```bash
pip install selenium ddddocr
```

> `tkinter` 為 Python 標準函式庫，通常已內建，無需另外安裝。

#### 套件說明

| 套件 | 版本建議 | 用途 |
|------|----------|------|
| `selenium` | `≥ 4.0` | 控制 Chrome 瀏覽器進行自動化操作 |
| `ddddocr` | 最新版 | OCR 模型，辨識網頁驗證碼圖片 |
| `tkinter` | 內建 | GUI 視窗介面 |
| `time` | 內建 | 計時與延遲控制 |
| `os` | 內建 | 驗證碼暫存圖片的讀寫與刪除 |

---

### 2. 安裝 ChromeDriver

ChromeDriver 版本**必須**與本機 Chrome 瀏覽器版本相符。

**Step 1**：確認 Chrome 版本  
開啟 Chrome → 右上角選單 → 說明 → 關於 Google Chrome，查看版本號。

**Step 2**：下載對應 ChromeDriver  
前往 [https://googlechromelabs.github.io/chrome-for-testing/](https://googlechromelabs.github.io/chrome-for-testing/) 下載對應版本。

**Step 3**：設定 ChromeDriver 路徑  
將 `chromedriver.exe` 放至以下任一位置：
- 與 `搶場機器人6_0.py` 同一資料夾
- 加入系統環境變數 `PATH`

> ⚠️ Selenium 4.6+ 已支援自動下載 ChromeDriver，若版本夠新可跳過此步驟，直接執行程式即可自動配對。

---

### 3. 執行程式

```bash
python 搶場機器人6_0.py
```

## 使用說明

啟動後會出現 GUI 視窗，依序填入以下欄位：

| 欄位 | 說明 | 範例 |
|------|------|------|
| **帳號** | 東華學號（會自動補上 `@gms.ndhu.edu.tw`） | `411225047` |
| **密碼** | 學校信箱密碼，可按 👁 切換顯示 | `****` |
| **運動類型** | 下拉選擇大類別 | 排球 |
| **場地** | 依運動類型自動更新對應場地清單 | `VOL0F排球場F-男` |
| **搶場時間** | 設定觸發搶場的精確時間（時/分/秒） | `12:00:00` |
| **場次** | 選擇欲預約的時段 | `17:00-19:00` |
| **借用原因** | 送出申請時填入的理由 | `我要練球` |
| **正式搶場** | 勾選 = 正式送出；未勾選 = 練習模式 | ✔ |

填寫完畢後按下「**開始搶場**」，GUI 視窗會關閉並自動開啟 Chrome 執行流程。

### 搶場日期邏輯

```
今日 → 下一週 → 下一週 → 前一天
= 兩週後的前一天
```

- **正式模式**：程式會監聽網頁伺服器時鐘，等到設定時間的最後一秒才觸發查詢
- **練習模式**：時間再往前一天（共兩週前兩天），且**不等待時間**，直接執行完整流程但**不送出**最終申請

## 運作流程

```
啟動 GUI
    │
    ├─ 填寫欄位 → 按下「開始搶場」
    │
    ▼
開啟 Chrome，前往東華體育場地借用系統
    │
    ├─ 輸入帳號密碼 → 登入
    │
    ├─ 點擊「新增申請」
    │
    ├─ 選擇運動類型、場地
    │
    ├─ 日期導航：今日 → +1週 → +1週 → -1天
    │
    ├─ [正式模式] 監聽伺服器時鐘，等待至設定秒數
    │
    ├─ 點擊「查詢」→ 點擊目標場次「申請」
    │
    ├─ OCR 辨識驗證碼（最多 10 次重試）
    │       ├─ 截圖 captcha.png
    │       ├─ ddddocr 辨識
    │       ├─ 填入驗證碼 → 點擊確認
    │       └─ 確認按鈕消失 → 驗證成功
    │
    ├─ 自動填入借用原因
    │
    ├─ [正式模式] 送出申請 → 顯示成功訊息
    └─ [練習模式] 顯示完成訊息（不送出）
```

## 常見錯誤與排查

### ❌ `SessionNotCreatedException` / ChromeDriver 版本不符

**原因**：ChromeDriver 版本與 Chrome 瀏覽器不符。

**解決**：
1. 確認 Chrome 版本（瀏覽器右上角 → 關於 Google Chrome）
2. 至 [Chrome for Testing](https://googlechromelabs.github.io/chrome-for-testing/) 下載對應版本
3. 或升級 Selenium 至 4.6+（支援自動管理 driver）

---

### ❌ `ModuleNotFoundError: No module named 'ddddocr'`

**原因**：未安裝 ddddocr。

**解決**：
```bash
pip install ddddocr
```

> 若安裝時出現 `onnxruntime` 相關錯誤，可嘗試：
> ```bash
> pip install onnxruntime --force-reinstall
> pip install ddddocr
> ```

---

### ❌ `ModuleNotFoundError: No module named 'selenium'`

**解決**：
```bash
pip install selenium
```

---

### ❌ 登入失敗 / 找不到登入按鈕

**可能原因**：
- 帳號密碼錯誤
- 系統網站暫時維護

**解決**：
1. 確認帳號（學號）與密碼正確
2. 手動嘗試登入 [東華體育場地借用系統](https://sys.ndhu.edu.tw/gc/sportcenter/SportsFields/Login.aspx)

---

### ❌ 驗證碼辨識失敗（超過 10 次）

**可能原因**：
- 驗證碼圖片解析度不足或模糊
- ddddocr 對特定字型辨識率較低

**解決**：
1. 確認 `ddddocr` 為最新版本：`pip install ddddocr --upgrade`
2. 若持續失敗，可手動調整程式碼中的 `max_retries` 參數（預設 10）

---

### ❌ 運動類型或場地選擇失敗

**可能原因**：
- 學校系統更新了場地名稱
- 選擇的場地文字與系統下拉選單不符

**解決**：
- 手動開啟借用系統，確認場地清單名稱，並更新程式碼 `venues_dict` 中的對應字串

---

### ❌ `TimeoutException`：等待元素逾時

**可能原因**：網路速度過慢，頁面載入超過預設等待時間（10~15 秒）。

**解決**：
- 確保網路連線穩定
- 可適當調大 `WebDriverWait(driver, 10)` 中的秒數

---

### ⚠️ 時間監聽失敗（`無法獲取時間`）

**原因**：找不到頁面上的 `currTime` 元素（伺服器時鐘）。

**解決**：
- 確認已進入正確的申請頁面
- 可先使用**練習模式**確認流程是否正常

---

## 注意事項

> 1. 本程式僅供**個人學習與研究**用途，請勿用於惡意搶占場地。
> 2. 預設帳號為範例值，請於 GUI 輸入欄修改為**自己的學號與密碼**，避免資安風險。
> 3. 程式會在驗證碼辨識過程中產生暫存檔 `captcha.png`，辨識後自動刪除。
> 4. 搶場完成後瀏覽器會**停留 20 秒**再關閉，方便確認結果。
> 5. 若學校系統更新 UI 或 HTML 結構，部分 XPath / Element ID 可能需要重新確認。
